## Editorial method

Each edition covers the preceding seven days, prioritizes primary or peer-reviewed sources, distinguishes evidence classes, and records material limitations. The brief does not pad the shortlist with weak or recycled items.

## Working in this repository

Before contributing, read [`AGENTS.md`](AGENTS.md). It defines the repository's operating rules and requires contributors to consult both the project-local learning memory and the organization-wide learning hub.

Project-specific knowledge belongs in [`lessons-learned/`](lessons-learned/README.md). Knowledge that could benefit other projects is also contributed to the central learning hub.
