# Lessons learned

This folder is this project's learning memory. Its purpose is to help future contributors avoid repeated mistakes, bypass known obstacles, reuse effective methods, and build on insights already discovered here.

## Before work

Read the existing lessons and any project-specific instructions or guides linked from this folder. Also consult the central learning hub at [`Shamdon/agent-lessons`](https://github.com/Shamdon/agent-lessons) and read the organization-wide material relevant to the task.

## Contributing

While working, remain alert for knowledge that could improve future work. Record it here when it is specific to this project.

Useful lessons include:

- a mistake and how it was corrected;
- an obstacle and an effective workaround;
- a successful or more efficient technique;
- a useful tool, skill, review, or evaluation practice;
- unexpected behavior or a non-obvious constraint; and
- an insight that changes how future work should be approached.

When another repository could realistically benefit, preserve the project-specific lesson here and also contribute a concise, generalized version to [`Shamdon/agent-lessons`](https://github.com/Shamdon/agent-lessons).

Write for the next contributor. Explain what was learned, why it matters, what to do next time, and the supporting evidence or experience. Use the form that communicates the lesson best; no fixed schema or promotion threshold is required.

Do not add routine logs, generic advice, temporary status, unsupported guesses, duplicated text, secrets, private data, or filler.
